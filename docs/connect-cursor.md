# Connect Cursor to WordPress

Cursor is an AI code editor. Once it's connected to your site, Cursor can work on your WordPress content, theme and settings while you build, all within the limits you set.

⏱️ About 2 minutes

## Before you start

- The **Secure MCP Server** plugin is installed and you've **created an agent**. If not, see [Getting started](getting-started.md).
- You have **Cursor** installed.

## Steps

### 1. Add the plugin to Cursor

Open **[MCP Server for WordPress on the Cursor Marketplace](https://cursor.com/marketplace/miniorange)** and click **Add to Cursor**.

**Or** type this command into Cursor's chat:

```text
/add-plugin mcp-server-for-wordpress
```

### 2. Click Add plugin

Cursor opens and asks you to confirm. Click **Add plugin**.

### 3. Enter your site's address

You'll land on the miniOrange sign-in page. Type or paste your site's address, for example:

```text
https://www.your-site.com
```

### 4. Sign in and approve

Your own WordPress login page opens. Log in with your usual WordPress account and click **Allow access**.

**That's it.** Cursor can now use the tools you allowed.

## Try it

> *"Look at my site and tell me which theme, page builder and plugins it uses."*

> *"Change the footer text in my theme, give me a preview, and publish it once I say yes."*

> *"Why aren't my scheduled posts publishing? Check cron and the error log."*

> 🛡️ **Theme changes are safe to try.** They go into a private draft that is checked for errors and previewed before going live. If the site breaks after publishing, the change rolls back automatically.

## Something not working?

See [Troubleshooting](troubleshooting.md), or open **Secure MCP Server → Troubleshooting** in WordPress to run a connection test.
