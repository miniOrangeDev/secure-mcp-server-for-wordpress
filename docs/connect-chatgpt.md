# Connect ChatGPT to WordPress

Once you're connected, you can ask ChatGPT to write posts, update products, fix SEO and more on your WordPress site, all from a chat.

⏱️ About 2 minutes · No code needed

## Before you start

- The **Secure MCP Server** plugin is installed and you've **created an agent**. If not, see [Getting started](getting-started.md).
- You have a **ChatGPT account** with access to apps and plugins. On business plans, your workspace admin may need to allow it first.

## Steps

### 1. Open the plugin page

Open **[MCP Server for WordPress](https://chatgpt.com/plugins/plugin_asdk_app_6a312802286c8191bad0a7278a4e53ef)** in ChatGPT and click **Install Plugin**.

> You can also start from the plugin. Go to **Secure MCP Server → Connect to AI**, choose **ChatGPT**, and the setup panel links you to the same page.

### 2. Click Sign in

Open the plugin in ChatGPT and click **Sign in**.

### 3. Enter your site's address

You'll land on the miniOrange sign-in page. Type or paste your site's address, for example:

```text
https://www.your-site.com
```

> 💡 The plugin shows your exact site address in the ChatGPT setup panel, with a copy button.

### 4. Sign in and approve

Your own WordPress login page opens. Log in with your usual WordPress account and click **Allow access**.

**That's it.** Start chatting with your site in ChatGPT.

> **Already started from ChatGPT?** If you installed the ChatGPT plugin first and were sent to WordPress to create an agent, just go back to that ChatGPT tab and click **Re-check** to finish.

## Try it

Start a new chat and ask:

> *"List the products in my store that are out of stock."*

> *"Export this month's Gravity Forms entries as CSV."*

> *"Add our new Pricing page to the main menu, right after About."*

## Something not working?

| What you see | What to do |
|---|---|
| ChatGPT can't reach your site | Make sure your site address starts with `https://` and opens in a private browser window. Then run the test in **Secure MCP Server → Troubleshooting**. |
| Connected, but ChatGPT sees no tools | Check that your agent is turned on and that your WordPress role has tools ticked in **AI Agents**. |
| It worked before but stopped | Disconnect the plugin in ChatGPT's settings and sign in again. |

More help: [Troubleshooting](troubleshooting.md) · [Full ChatGPT guide on miniOrange's website](https://plugins.miniorange.com/setup-chatgpt-to-wordpress-abilities-api-using-mcp)
