# Security policy

Security is the core of this plugin, and we take reports seriously.

## Reporting a vulnerability

**Please don't report security issues in public GitHub issues or the WordPress.org forum.**

Instead, email **info@xecurify.com** with:

- A description of the issue and its impact
- Steps to reproduce it
- The plugin version, WordPress version and PHP version
- Any proof-of-concept code or screenshots

We'll confirm we've received your report, keep you updated while we investigate, and credit you in the changelog if you'd like.

## Supported versions

Security fixes are released for the **latest version** of the plugin on [WordPress.org](https://wordpress.org/plugins/miniorange-secure-mcp-server/). Please keep the plugin updated.
